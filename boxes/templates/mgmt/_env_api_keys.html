API Keys and Environment

Integration keys are loaded from /etc/boxes.env on the server (not from this form). Values are never shown here — only whether each variable is set and looks valid. Restart gunicorn and celery after edits.

Canonical environment variables
Stripe
  • STRIPE_PUBLISHABLE_KEY — public (pk_…)
  • STRIPE_SECRET_KEY — private (sk_…)
  • STRIPE_WEBHOOK_SECRET — webhook (whsec_…)
Mailjet
  • MJ_APIKEY_PUBLIC / MJ_APIKEY_PRIVATE (send mail)
  • MAILJET_WEBHOOK_SECRET — invent in /etc/boxes.env; same value on Mailjet Event API URL as ?secret=… (/webhooks/mailjet)

Stripe API keys (pk_ / sk_) are separate from the Stripe webhook signing secret (whsec_). Mailjet has its own webhook at /webhooks/mailjet, independent of Stripe.
